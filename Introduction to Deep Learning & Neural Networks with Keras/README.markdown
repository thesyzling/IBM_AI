# Introduction to Deep Learning & Neural Networks with Keras

This repository contains materials, code, and projects related to the Coursera course **Introduction to Deep Learning & Neural Networks with Keras** offered by IBM. The course provides a comprehensive introduction to deep learning concepts and practical implementation using the Keras library.

## Course Overview

The **Introduction to Deep Learning & Neural Networks with Keras** course is designed for learners with some programming and machine learning experience who want to dive into deep learning. Taught by Alex Aklson, this intermediate-level course covers foundational and advanced deep learning concepts, focusing on building and evaluating neural network models using Keras. The course is structured into 5 modules and takes approximately 10 hours to complete, with a flexible schedule.

### What You'll Learn
- **Foundational Concepts**: Understand the basics of deep learning, neurons, and artificial neural networks to solve real-world problems.
- **Neural Network Components**: Explore core concepts like gradient descent, backpropagation, and activation functions, and address training challenges such as the vanishing gradient problem.
- **Building Models with Keras**: Develop regression and classification models using Keras and interpret their performance metrics.
- **Advanced Architectures**: Design convolutional neural networks (CNNs), recurrent neural networks (RNNs), transformers, and autoencoders for tasks like image classification and language modeling.

### Course Structure
The course is divided into 5 modules:
1. **Module 1**: Introduction to deep learning, neurons, artificial neural networks, and forward propagation.
2. **Module 2**: Neural network mechanisms, including gradient descent, backpropagation, activation functions, and handling vanishing gradient issues.
3. **Module 3**: Practical applications of deep learning with Keras, including building regression and classification models.
4. **Module 4**: Advanced architectures like CNNs, RNNs, transformers, and autoencoders, with hands-on labs.
5. **Module 5**: Final project integrating deep learning concepts for tasks like image classification and caption generation.

## Getting Started
To use the materials in this repository, follow these steps:

### Prerequisites
- Python 3.7 or higher
- Keras (with TensorFlow backend)
- Jupyter Notebook or JupyterLab
- Basic knowledge of Python programming and machine learning concepts

### Installation
1. Clone the repository:
   ```bash
   git clone https://github.com/thesyzling/IBM_AI.git
   cd IBM_AI/Introduction%20to%20Deep%20Learning%20%26%20Neural%20Networks%20with%20Keras
   ```
2. Install the required dependencies:
   ```bash
   pip install -r requirements.txt
   ```
3. Open Jupyter Notebook to explore the notebooks:
   ```bash
   jupyter notebook
   ```

### Requirements
The `requirements.txt` file includes the necessary Python packages:
```
tensorflow>=2.0.0
keras>=2.2.0
numpy
pandas
matplotlib
jupyter
```

## Usage
- **Assignments**: Navigate to the `assignments/` folder to view solutions for the 8 course assignments.
- **Hands-on Labs**: Explore the `notebooks/` folder for practical exercises on building and training models.
- **Final Project**: Check the `projects/` folder for the code and documentation of the final project, which integrates image classification and caption generation.
